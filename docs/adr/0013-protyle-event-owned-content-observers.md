# Let Protyle events own content-observer lifecycles

Linkmark discovers existing Link content containers once at startup and then treats SiYuan's Protyle lifecycle events as the authority for registering and disconnecting per-container mutation observers. Registration immediately scans the container, while its observer handles later editor mutations and asynchronous Preview replacement. Full discovery traverses every registered container that remains connected to the document, including containers in hidden tabs and inactive modes, because Present means mounted rather than visible. Linkmark deliberately does not retain a `document.body` subtree observer as a fallback for third-party DOM changes that bypass Protyle creation and destruction: SiYuan has no narrower common DOM ancestor across tabs, mobile editors, and block panels, and observing the whole body would preserve the application-wide mutation noise this boundary is intended to remove.
