## 更新内容

### 新功能：链接右键菜单

- 对任意外部链接点击右键即可操作图标：
  - **重新获取图标**：将该链接对应域名重新排队解析，完成后图标自动更新；已固定的图标不受影响。
  - **更换并固定图标…**：打开选择器更换图标并固定，固定图标不会被日常刷新与缓存清理改动。
- 固定图标与自动获取的边界保持不变：右键刷新会明确提示固定图标未被更改。

### 开发依赖升级

- **siyuan 升级至 1.2.3**：改用官方 npm 包自带的 API 类型声明，移除手写 `src/siyuan.d.ts` 与 tsconfig 路径映射，减少本地声明与官方 API 漂移的风险。

**完整变更**: https://github.com/kasuha07/siyuan-linkmark/compare/v0.1.4...v0.2.0
