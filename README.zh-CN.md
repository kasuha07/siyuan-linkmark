# Linkmark 链接印记

[![CI](https://github.com/kasuha07/siyuan-linkmark/actions/workflows/check.yml/badge.svg)](https://github.com/kasuha07/siyuan-linkmark/actions/workflows/check.yml)

链接印记自动为思源链接发现、显示并本地缓存网站图标。无法获得真实 favicon 时，可以在本地生成彩色域名字母图标。

## Fork 与核心差异

链接印记独立于上游项目维护。用户可感知的核心差异为：

- **独立渲染图标：** 链接印记不检测、保留或优先其他插件的图标，而是独立渲染自身选定的图标。
- **工作区共享缓存：** 图标获取、缓存策略和缓存管理由思源内核负责，在连接同一工作区的所有客户端中共享。

## 主要功能

- 默认从域名根页面、常见根目录图标（`/favicon.svg`、`/favicon.png`、`/apple-touch-icon.png`、`/favicon.ico`）、Web App Manifest 和可选图标服务发现网站图标，不访问包含文档 ID 的具体路径。
- 识别腾讯文档、飞书/Lark、Google Docs 的稳定路径类型，以及 NoCode 的公开应用部署路径，让同一域名下的不同站点或内容类型显示各自图标。
- 提供普通网络、代理网络和只访问链接网站三种策略。
- 将验证通过的图标缓存在思源工作空间，后续直接读取本地文件。
- 支持全局及按域名设置字母、颜色和形状。
- 支持为域名上传自定义图片、填写图片 URL，或从发现的候选图标中选择，并可选择让其子域名共用。
- 通过顶部工具栏快速刷新当前文档、管理缓存或打开设置。
- 可暂停后台自动获取；也可明确授权访问具体页面或在候选窗口进行一次性页面探测。

## 功能与用途

| 功能 | 用途 |
| --- | --- |
| 自动显示网站图标 | 扫描思源文档中的 HTTP/HTTPS 链接，在链接前显示网站图标。关闭后停止显示和自动处理，但不会删除缓存。 |
| 路径类型图标 | 只对腾讯文档、飞书/Lark、Google Docs 和 NoCode 等已适配平台识别稳定路径类型，使同一域名下的不同站点或内容类型显示不同图标；普通网站仍按域名处理。 |
| 暂停自动获取 | 调试或整理缓存时阻止后台联网和自动重建。已有缓存（包括过期缓存）继续显示，手动刷新、更换和上传图标仍然可用。 |
| 允许访问具体链接页面 | 默认关闭。需要网站为不同页面声明的专属 favicon 时才开启；插件只向原网站请求去掉参数和锚点的路径。 |
| 加载页面专属候选 | 不改变全局设置，只对当前这一次候选加载授权访问具体页面，适合偶尔寻找某个页面的专属图标。 |
| 获取策略 | “普通网络”兼顾国内可用性和成功率；“代理网络”增加 Google、DuckDuckGo 来源；“只访问链接网站”不使用第三方图标服务。 |
| 第三方图标服务 | 当网站自身没有可用图标时，按域名向 FaviconKit、favicon.im 等服务查询；不会发送文档路径、标题或 token。 |
| 无图标时生成彩色字母 | 所有真实图标来源都失败后，在本地生成稳定的域名字母图标，避免链接前留下空白。 |
| 字母图标样式 | 调整字母图标的配色、文字和形状，也可为特定域名单独设置；不会影响已经取得的真实 favicon。 |
| 图标尺寸 | 调整链接前图标相对正文文字的大小，不改变缓存文件本身。 |
| 缓存有效期 | 控制自动图标多久重新检查一次；设为 `0` 表示不因时间自动过期。固定图标不受有效期影响。 |
| 刷新当前文档 / 全部缓存 | 主动重新获取当前文档或全部非固定缓存；即使暂停自动获取也可以执行。刷新失败时保留原来的可用图标。 |
| 缓存管理 | 按域名查看各路径类型及来源，单独刷新、删除或更换图标；适合处理模糊、留白、边框和图标选择不理想的问题。 |
| 固定图标范围 | “当前类型”只影响如 `/doc/` 或 `/sheet/` 的同类链接；“当前域名”用于该域名的所有未单独固定类型；“上级域名及子域名”在真正的可注册域名内让子域名共用一个图标，且绝不对公共后缀或托管型多租户站点（如 `github.io`）提供该选项。 |

## 图标选择优先级

插件先从本地固定项和缓存中选择；只有没有可用项时才进入联网解析。优先级从高到低为：

1. 当前路径类型的固定图标，例如 `docs.qq.com::sheet`。
2. 当前域名的固定图标。
3. 设置为“应用到所有子域名”的上级域名固定图标。
4. 当前路径类型的有效缓存。
5. 当前域名的有效缓存；它也可作为尚未建立类型缓存时的临时兜底。
6. 本地识别出的办公平台类型图标。
7. 当前域名根页面声明的 `rel=icon`、Web App Manifest 图标和常见根目录图标文件。
8. 合法上级域名的页面声明、Manifest 和常见根目录图标文件。
9. 当前域名的第三方图标服务结果。
10. 上级域名的第三方图标服务结果。
11. 本地彩色域名字母图标。

开启“允许访问具体链接页面”或点击“加载页面专属候选”后，具体页面声明的 `rel=icon` 和 Manifest 图标会插入到第 6 项之前。该授权不会改变固定图标和已有缓存的优先级。

## 缓存策略

打开文档时插件会扫描其中的网页链接，但有效缓存会直接从本地读取，不会再次访问外部网络。只有首次出现、已经过期、文件丢失或损坏、解析版本变化，或者用户主动刷新时才会重新获取。

- 默认有效期为 30 天。
- 填写 `0` 表示一直保留，直到手动清理。
- 本地生成的彩色字母也遵循相同有效期。
- 获取失败后，本次插件运行期间暂停重试 10 分钟。
- 主动刷新失败时继续使用原有图标，不会先删除可用缓存。
- 手动选择的图标会固定保存在本地，普通缓存清理和过期不会删除；恢复自动获取后才解除。
- 图标内容与 `favicon-cache-v2.json` 索引均保存在链接印记的插件私有存储中；普通缓存只保留域名，已适配平台的缓存可额外保留 `doc`、`sheet`、`base` 或 NoCode 公开部署标识等稳定路由，不保存参数、锚点或标题。
- 链接印记不会导入或删除先前 `auto-favicon` 插件的设置、缓存项或固定图标。
- 开启“暂停自动获取”后，已有及过期缓存继续显示，删除缓存后不会自动重建；手动刷新、更换候选和上传图片仍可使用。

缓存管理支持重新获取当前文档、重新获取全部自动缓存域名、搜索缓存，以及单独刷新或删除某个域名。

## 图标不理想时

同一网站可能同时提供多枚图标，不同来源的清晰度、留白和边框也可能不同。如果自动获取的图标模糊、带边框或样式不合适，可打开顶部工具栏的“管理缓存”，找到对应域名并点击“更换图标”：

![为域名选择候选图标](icon-picker.png)

- 从插件发现的安全候选中选择；候选卡片会显示来源、像素尺寸、格式和文件大小。
- 默认不访问具体链接；需要页面专属 favicon 时，可点击“加载页面专属候选”进行一次性授权。
- 上传一张本地图片。
- 填写可直接访问的图片 URL。

手动选择的图标会被固定保留，不会被普通刷新、缓存过期或“清除全部缓存”覆盖。对办公平台可选择仅应用于当前类型或整个域名；更广的“上级域名”范围只在可注册域名符合条件时提供，不会对 `github.io` 之类的公共后缀租户或多租户平台边界（如 `qq.com`、`google.com`、`feishu.cn`、`larksuite.com`、`nocode.host`）开放。需要重新交给插件自动获取时，点击“恢复自动获取”即可。

## 网络与隐私

- **普通网络：** 当前域名、合法上级域名及所选图标服务，不请求 Google 或 DuckDuckGo。
- **代理网络：** 额外尝试 Google 和 DuckDuckGo，尽量提高成功率。
- **只访问链接网站：** 仅访问当前域名和合法上级域名，失败后使用本地兜底图标。

默认情况下，自动获取不会访问包含文档 ID 的完整链接。平台类型根据 URL 在本地识别；为区分 NoCode 同一域名下的公开部署站点，插件会访问该站点的部署入口。第三方服务只会收到域名。其他具体路径只有开启“允许访问具体链接页面”，或主动点击“加载页面专属候选”后才会被请求。所有路径请求都会去掉参数和锚点，不携带 Cookie、Authorization 或 Referer，登录页重定向图标会被丢弃。

插件不会把 localhost、`.local`、回环、链路本地和私有 IP 地址发送给图标服务，也不会向第三方服务发送笔记内容、锚文本、文档路径或 token。

## 安装与使用

可直接在思源集市搜索 **Linkmark（链接印记）** 并安装；也可以把 `package.zip` 解压到 `工作空间/data/plugins/siyuan-linkmark/`。启用插件，在设置中选择网络策略，然后使用顶部工具栏的链接印记按钮执行常用操作。
